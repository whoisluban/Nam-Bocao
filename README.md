## 🚀 Cómo ejecutar en local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/nam-bocao.git
   cd nam-bocao
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. Compilar para producción:
   ```bash
   npm run build
   ```

## 🌐 Publicar en GitHub Pages

Este repositorio ya incluye el workflow automatizado `.github/workflows/deploy.yml`.

Para activarlo en GitHub:
1. Ve a tu repositorio en GitHub > **Settings** (Configuración).
2. En la barra lateral izquierda, entra en **Pages**.
3. En **Build and deployment** > **Source**, selecciona **GitHub Actions**.
4. ¡Listo! Cada vez que hagas `git push` a la rama `main`, la página se compilará y se publicará automáticamente en tu URL de GitHub Pages.
